-----------------

1. Coefficients c_k:
   - Derived using normalization pattern: c_10 = (-1)^10 = 1, c_9 = 2(10-3)(-1)^9 = -14
   - Remaining coefficients solved from moment constraints (0, 1, 3, 5, 7, 9)
   - d_K = 286 calculated from moment 2

2. Parameter κ:
   - Table I shows κ converging: 1.69→1.75→1.82→1.84→1.86→1.88→1.89
   - Increments decreasing: 0.06→0.07→0.02→0.02→0.02→0.01
   - K=8 and K=9 values (1.88, 1.89) suggest convergence near 1.88-1.89
   - κ = 1.88 chosen as conservative estimate (could use 1.89)

3. Parameter α:
   - Exponential fit using K≥5 data: α(K) ≈ 9973.4 × exp(-1.255 × K)
   - R² = 0.9996 (excellent fit)
   - Predicts α(10) = 0.0355 × 10⁻³
   - Rounded to α = 0.036 × 10⁻³ for practical use
   - Alternative methods (ratio extrapolation) give 0.034-0.041 × 10⁻³
