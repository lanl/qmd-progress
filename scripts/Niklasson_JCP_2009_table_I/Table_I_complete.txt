NOTES:

1. Normalization Pattern (determines last two coefficients):
   c_K = (-1)^K
   c_{K-1} = 2(K-3)(-1)^(K-1)

2. Recursive d_K Relationship:
   d_{K+1} = |c_0(K)|

   Examples:
   - d_4 = |c_0(K=3)| = |-2| = 2
   - d_5 = |c_0(K=4)| = |-3| = 3
   - d_6 = |c_0(K=5)| = |-6| = 6
   - d_7 = |c_0(K=6)| = |-14| = 14
   - d_8 = |c_0(K=7)| = |-36| = 36
   - d_9 = |c_0(K=8)| = |-99| = 99
   - d_10 = |c_0(K=9)| = |-286| = 286
   - d_11 = |c_0(K=10)| = |-858| = 858

3. Moment Constraints:
   For each K, coefficients c_0 through c_{K-2} are solved from K-1 equations:
   - Moment 0: Σ c_k = 0
   - Moment 1: Σ k·c_k = 0
   - Odd moments 3, 5, 7, ..., until K-1 equations total

   The value d_K is then calculated from moment 2:
   - d_K = (Σ k²·c_k) / 2

4. K=10 Extension:
   - Coefficients c_k derived using the same normalization and constraint system
   - Successfully extends the XLBO dissipation scheme to 11-point history

   * K=10 parameters (extrapolated):
     κ = 1.88: Converged value based on K=8,9 trend (Δκ decreasing: 0.02→0.01)
     α = 0.036 × 10⁻³: Exponential fit using K≥5 data (R²=0.9996)

   Note: κ and α should be validated via stability analysis for production use.
